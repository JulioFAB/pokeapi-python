# Proyecto PokeAPI

Este proyecto usa Python para consultar datos de Pokémon desde la API pública [PokeAPI](https://pokeapi.co/).

En este proyecto decidi usar python debido a que se me solicitaba un lenguaje de programacion y un repositorio, y aunque es posible hacerlo desde postman, que es como sé probar una API, me parecio más practico hacerlo con python y pycharm. Me apoye de la IA para poder hacer un codigo simple y funcional que permite cumplir con la tarea desde un lenguaje de programacion

# Instalación
Es necesario contar con un IDE de python
Se debe descargar la libreria requests
